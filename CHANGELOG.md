# Changelog

Все заметные изменения этого проекта фиксируются здесь.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

Источник версии — поле `version` в `package.json`. Команда `/version` и лог запуска читают его напрямую.

## [0.4.1] - 2026-10-22

### Fixed

- Фильтрация широкого спреда и нерыночных Ask-котировок в ленте IEX (`resolveEntryReferencePrice`, допуск `0.25%`) с опорой на цену последней сделки (`getSnapshot`) и закрытие минутной свечи
- Валидация актуальности пробоя при нажатии «Купить» (`validateEntryTiming`): отклонение входа при уходе цены в `chase` или падении ниже `VWAP`/`rangeLow`
- Перестановка стоп-лосса и тейк-профита (`replaceLegs`) выполняется до отправки уведомления «Куплено» + добавлена быстрая проверка ордера через `1.5 сек` после покупки
- Корректный пересчёт `legsFromFill` с учётом технического уровня `rangeLow` и увеличение `MAX_STOP_PCT` с `1.2%` до `1.6%` для защиты от выбивания на ретесте пробоя
- Форматирование строки счёта (`formatAccountNote`) без `undefined` при отсутствии устаревших полей `pattern_day_trader` / `daytrade_count` в ответе Alpaca API

## [0.4.0] - 2026-10-21

### Added

- Нативное меню команд Telegram (`setMyCommands`, `setChatMenuButton`) и нижняя панель быстрых кнопок (`Баланс`, `Позиции`, `План`, `Скан`, `Новости`, `Журнал`), вызываемая по `/start` и `/menu`
- Команда `/news [ТИКЕР]` и кнопка «Новости»: загрузка свежих новостей и котировок из Alpaca с переводом и краткой аналитической выжимкой через OpenAI (и fallback на заголовки Alpaca при недоступности ИИ)
- Режим свободного чата с ИИ-ассистентом: ответ на текстовые вопросы по рынку, тикерам, новостям, текущим позициям и идеям дня на основе живых данных Alpaca

## [0.3.1] - 2026-10-21

### Added

- Итоговое уведомление в Telegram в `11:00 ET` со сводкой причин отсева, если за окно `09:46–11:00 ET` не было ни одного пробоя
- Логирование старта/завершения окна ORB и найденных сигналов в `stdout` (`out.log`)
- Запись причин отсева (`filter`) по тикерам в `data/journal.jsonl` по завершении окна сканирования для отображения в `/journal`
- Настройка `MAX_RANGE_PCT` через переменные окружения и вывод текущего отсева в `/scan`

### Changed

- Порог `RVOL_MIN` по умолчанию снижен с `1.5` до `1.1` с учётом доли утреннего объёма в ленте IEX
- Максимальная ширина диапазона открытия `MAX_RANGE_PCT` увеличена с `2.0%` до `2.5%`
- Кэширование расчёта минут NY и предгруппировка баров для ускорения `npm run backtest`

## [0.3.0] - 2026-10-20

### Added

- Утренний поиск пробоя 15-минутного диапазона (ORB) по списку акций, 09:46–11:00 ET
- Карточки в Telegram с пояснением OpenAI и кнопкой «Купить» (лимитный bracket: стоп и цель на стороне Alpaca)
- Сопровождение позиции: уведомления о fill/стоп/цели, сигнал к продаже, перенос стопа в безубыток после 1R
- Безопасный выход: сначала отмена ног bracket, затем закрытие позиции; автозакрытие за 5 минут до `next_close` (`AUTO_FLATTEN`)
- Команды `/scan`, `/plan`, `/journal`
- Журнал сделок `data/journal.jsonl` и бэктест `npm run backtest` на истории IEX
- Юнит-тесты правил рынка и выхода (`npm test`)

### Changed

- `OPENAI_API_KEY` обязателен при старте бота

## [0.2.0] - 2026-10-19

## [0.1.0] - 2026-10-19

### Added

- Telegram-бот на Telegraf для paper-счёта Alpaca
- Команды `/start`, `/account`, `/positions`, `/quote`, `/buy`, `/sell`
- Рыночные day-ордера только после кнопки «Подтвердить»
- Доступ только для `TELEGRAM_ALLOWED_USER_ID`
- Тонкий HTTP-клиент Alpaca без SDK, URL paper зашит в код
